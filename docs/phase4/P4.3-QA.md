## Verification

- Desktop geographic map renders with the map-room backdrop, raised selected constituency, detail
  sheet, overlay legend, icon zoom controls, and mini status readout.
- Narrow layout collapses the selected-region detail into a compact strip and hides the expanded
  legend body so the short map band remains readable.
- Hex renderer was switched on in-browser and reported 650 visible polygons.
- Overlay semantics use shared visual metadata: player commitments use a solid rail, opponent
  activity uses a dotted rail, contests use a dashed rail, and disabled regions use hatching.
- Keyboard support is present on the map surface for zoom in/out, reset, arrow-key pan, and Escape
  to clear an active region.
