## Checks

- Desktop viewport: title, new-game setup, selected party state, loading, load-game, and restore
  success were captured against the current worktree Vite server.
- Narrow viewport: title, new-game setup, loading, and load-game were captured at 320px width.
  DOM checks reported `scrollWidth === innerWidth` for the narrow title/new-game/load/loading
  passes.
- Keyboard operation is preserved through native buttons, range input, focus-visible styling, and
  unchanged store actions.
- High-contrast support is covered by the shared `forced-colors` rules added to the P4.1 surface
  classes.
- Reduced-motion support is covered by the global reduced-motion rule and a static fallback for the
  branded map trace.
