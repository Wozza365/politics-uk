## Verification

- Polling chart uses the shared data-visualisation theme for axis, grid, tooltip, line emphasis,
  and a latest-poll text/table summary.
- Hemicycle and house view now use labelled party chips, top-party stat tiles, seats-per-dot copy,
  and accessible SVG summaries instead of colour-only interpretation.
- Northern Ireland parties are grouped as `NI`; Speaker and independent seats are grouped once as
  `Ind` so the legend does not duplicate the same seat family.
- Compass view has quadrant tinting, a subtle analytical grid, labelled points in full mode, and
  exact coordinate text in its accessible label.
- Contest cards now use HUD records, icon map/explain affordances, and action descriptions that
  remain visible while comparing options.
