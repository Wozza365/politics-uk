## Checks

- 320px overflow scan: passed after shortening the compact hemicycle label to `Seats`.
- Reduced motion: in-app reduced-motion setting and OS `prefers-reduced-motion` both remove motion-heavy transitions.
- Reduced sensory: sound is off by default and can be disabled via reduced sensory mode.
- Colour/non-colour cues: map overlays use rails/dashes/hatching, feed cards use labels/icons plus colour, and status states use text.
- Forced colours: HUD surfaces, controls, modal surfaces, map controls, and save thumbnails retain borders and text.
- Release assets: favicon, app icon, manifest, and asset-rights notes are present.
