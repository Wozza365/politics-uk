### P4.7 - Event presentation, microcopy, and narrative tone `DONE`

**Goal.** Make events, actions, explanations, tutorials, and results feel like part of one polished
political drama. The writing should be concise, credible, and mechanically clear without adding
visible feature-explainer clutter.

**Depends on.** P4.0 tone direction. Coordinates with P4.2, P4.4, and P4.5.

**Steps:**

1. Define a tone guide: sober, sharp, election-night credible, lightly dramatic when stakes rise,
   never meme-like, never defamatory, and never pretending fictional simulation output is real
   reporting.
2. Redesign event-feed cards with hierarchy: scope/severity/date, headline, action taken, effect
   summary, explain affordance, and new/unresolved/resolved states. Use icons or chips for scope and
   severity where helpful.
3. Improve action-choice presentation: labels, cost/resource impact, likely effect range, target,
   cooldown or consequence, and disabled reason. The player should understand tradeoffs quickly
   without reading paragraphs.
4. Polish explanation surfaces so they feel like an audit trail, not debug output: grouped factors,
   weighted contributors, concise model language, and clear distinction between direct effects,
   background drift, and estimated data.
5. Refine tutorial/help copy. Keep onboarding contextual and dismissible; avoid visible text that
   merely describes what the UI looks like or repeats obvious button behaviour.
6. Standardise date, number, money, polling, seat, majority, and delta formats across screens.
   Numbers should be brief, localised to en-GB, and consistent between cards, tooltips, and results.
7. Add a content QA pass for line length, truncation, offensive/unsafe generated wording, political
   neutrality, and real-person sensitivity.

**Files:** `EventFeed.vue`, `TutorialOverlay.vue`, `HelpPanel.vue`, `ExplanationDetails.vue`,
`TargetOptionRow.vue`, `LeverCard.vue`, `ContestCard.vue`, result/new-game copy surfaces, event
data if copy changes, formatting helpers, and content QA notes.

**Acceptance:** event and explanation UI feels premium and credible. Common actions can be compared
at a glance, long copy does not overflow compact panels, and politically sensitive text is handled
carefully with clear simulation/provenance language.
