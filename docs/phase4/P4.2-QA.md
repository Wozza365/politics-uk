- Desktop viewport: game HUD, event feed, clock controls, goal strip, journal, view switcher,
  game menu, save panel, and expanded party panel were captured against the current worktree Vite
  server.
- Narrow viewport: game HUD was captured at 320px width after fixing compact party-header overlap
  and shortening the Westminster tab to `Commons`.
- DOM overflow check reported `scrollWidth === innerWidth` for the 320px game capture.
- Shared primitives now cover HUD panels, panel headers, icon buttons, segmented controls, status
  pills, stat tiles, modal surfaces, drawer panels, and tooltips.
- `@lucide/vue` is the single icon dependency for HUD controls introduced in this pass.
