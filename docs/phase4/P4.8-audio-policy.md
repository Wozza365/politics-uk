# P4.8 Audio Policy

Completed on 2026-07-01.

## Policy

- Sound is off by default.
- Cues only play after the player enables sound in Presentation settings.
- Muted/reduced-sensory play remains fully functional because every cue is paired with visible UI state.
- Preferences are stored in localStorage, not campaign saves.
- Ambience is reserved but no loop plays in this build.

## Cue Palette

- Panel open: short two-tone confirmation.
- Save complete: short rising cue.
- Event arrival: low-to-mid cue.
- Action resolved: firm confirmation cue.
- Warning/save failure: descending triangle cue.

## Assets and Rights

- No external audio files are bundled.
- Cues are generated at runtime with the WebAudio oscillator API.
- There are no third-party audio licences to track for this implementation.

## Replacement Procedure

If authored audio files are added later, document file path, source, licence, duration, loudness
target, and replacement scope here before shipping them.
