# P4.6 Asset Notes

Completed on 2026-07-01.

## Iconography

- Runtime icon library: `@lucide/vue`, already present in `package.json`.
- Shared icon-button sizing remains in `IconButton.vue` and `.hud-icon-button`.
- Title, setup, and load navigation controls now use lucide icons instead of text glyphs where a familiar symbol exists.

## Party Identity

- `PartyMark.vue` renders party short names inside a consistent geometric mark using verified scenario party colours.
- Official party logos are not bundled. The current marks are project-generated placeholders and do not claim official branding.
- `LeaderPortrait.vue` renders consistent leader/officer placeholders from initials, scenario party colours, and a generic silhouette. No politician photography is bundled.

## App Assets

- `public/favicon.svg` and `public/app-icon.svg` are project-owned SVG marks: a ballot shield with Westminster bench lines.
- `public/manifest.webmanifest` references `app-icon.svg` for installable-app contexts.
- Starter/demo SVG assets were removed from `public/icons.svg` and `src/assets/vite.svg` because they were unused and not part of the product identity.

## Replacement Procedure

1. Add a licensed logo or portrait path to scenario party/officer data only after rights are documented.
2. Keep `PartyMark.vue` and `LeaderPortrait.vue` as fallbacks when an asset is missing.
3. Update this note with source, licence, date acquired, and replacement scope before shipping third-party imagery.
