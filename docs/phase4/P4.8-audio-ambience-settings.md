### P4.8 - Audio, ambience, and player presentation settings `DONE`

**Goal.** Add optional, tasteful presentation polish beyond visuals: sound cues, ambience, and
settings that make the game feel finished while keeping it usable in silence.

**Depends on.** P4.0 and P4.5. Can be skipped if the product decision is "visual only", but the
settings surface should still leave room for presentation preferences.

**Steps:**

1. Decide the audio policy: off by default until explicit player interaction, mute always available,
   local preference persistence, no autoplay surprises, and no dependency on audio for gameplay
   meaning.
2. Define a small sound palette: button confirm, panel open/close, save complete, event arrives,
   action resolved, objective complete, warning/destructive action, election day/result reveal, and
   optional low-volume ambience. Avoid looping audio unless the player can disable it quickly.
3. Implement an audio manager/composable with volume categories, mute, reduced-sensory preference,
   preloading/fallback, and no hard coupling to stores beyond events it needs to observe.
4. Add presentation settings: sound effects volume, ambience volume if used, reduced motion,
   high-contrast/colour-assist mode if P4.9 identifies a need, and compact/dense HUD preference if
   it emerges from responsive QA.
5. Pair important audio cues with visual feedback from P4.5. For example, save complete should also
   show a status change; event arrival should also create a visible feed state.
6. Document asset source/licensing for any audio files. If generating sounds, record prompts/tools
   and keep files small.

**Files:** new audio assets under `public/` or `src/assets/`, audio manager/composable, UI store or
preferences storage, settings panel/screen, relevant HUD components, tests where feasible, and
asset notes.

**Acceptance:** the game works perfectly muted, but optional cues add polish after player opt-in.
Audio preferences persist locally, no autoplay violation occurs, cues never replace visual state,
and all audio assets have documented origins/rights.
